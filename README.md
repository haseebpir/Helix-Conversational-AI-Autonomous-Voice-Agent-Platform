## ✨ Overview

**Helix** is an enterprise-focused conversational AI platform designed to simplify the creation, simulation, and deployment of autonomous voice agents. Its all-in-one workspace helps teams configure AI models, provide contextual documentation, preview voice synthesis, and monitor agent performance from a centralized console.

I shaped the foundational experience and responsive web application for Helix, combining an intelligent multi-model prompt bar with a dark-canvas analytics dashboard. The result is a streamlined workspace that transforms complex AI configuration into an intuitive, transparent, and efficient workflow for building automated customer support experiences.
